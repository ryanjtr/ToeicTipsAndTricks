Study Skills
============

Từ: get the hang of something
Loại từ: phrase
Phiên âm: /ɡɛt ðə hæŋ əv ˈsʌmθɪŋ/
Nghĩa: Làm quen với điều gì đó, nắm bắt kỹ thuật
Câu ví dụ: It took some time for the student to get the hang of using the new computer software for exam preparation.
Dịch câu: Học sinh mất một thời gian để làm quen với việc sử dụng phần mềm máy tính mới cho việc ôn thi.
